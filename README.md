# JavaScript Array Methods Implementation

This repository contains my practice implementations of JavaScript's built-in Array methods using basic JavaScript logic, without directly using the original built-in methods.

The purpose of this project is to understand how JavaScript array methods work internally and improve my problem-solving and programming skills.

## Implemented Methods

- `myPush()` – Adds elements to the end of an array.
- `myPop()` – Removes the last element.
- `myUnshift()` – Adds elements at the beginning.
- `myShift()` – Removes the first element.
- `myMap()` – Creates a new array by transforming elements.
- `myFilter()` – Creates a new array containing elements that pass a condition.
- `myForEach()` – Executes a callback function for each element.
- `myFind()` – Returns the first element that matches a condition.
- `myIncludes()` – Checks whether an element exists in an array.
- `myIndexOf()` – Returns the index of an element.
- `myReverse()` – Reverses the array.
- `myReduce()` – Reduces an array to a single value.
- `mySort()` – Sorts array elements in ascending numeric order.
- `mySlice()` – Returns a portion of an array without modifying the original.
- `mySplice()` – Adds or removes elements from an array.
